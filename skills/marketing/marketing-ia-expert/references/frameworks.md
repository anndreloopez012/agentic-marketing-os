# Marketing IA Frameworks

Use these frameworks to structure professional outputs.

## Professional Prompt Formula

Act as [role].
Context: [business, product, audience, objective].
Task: [specific work].
Format: [table, list, calendar, script, report].
Restrictions: [tone, length, channel, style].
Quality criteria: [what the answer must satisfy].

## Brand Diagnosis

Analyze:
- What the brand sells.
- Who it sells to.
- What problem it solves.
- Main promise.
- Tone and personality.
- Differentiator.
- Objections.
- Content opportunities.
- Positioning risks.

## Buyer Persona

Include:
- Name, age, occupation/context.
- Problems and pains.
- Desires and motivations.
- Objections before buying.
- Content consumed.
- Message that convinces.
- Offer that could work.
- Trigger event for purchase.

## Content Pillar Matrix

Use eight content families:
1. Educational.
2. Authority.
3. Trust.
4. Entertainment.
5. Sales.
6. Community.
7. Social proof.
8. Objections.

Each idea should include: format, hook, objective, CTA, funnel stage.

## Hook Types

- Pain: names a concrete problem.
- Curiosity: opens a gap.
- Common error: challenges behavior.
- Promise: clear result.
- Contrast: before/after or myth/truth.
- Story: specific situation.
- Direct question: audience self-identifies.

## Copywriting Structures

AIDA: Attention -> Interest -> Desire -> Action.
PAS: Problem -> Agitation -> Solution.
Before/After: current state -> desired state -> bridge.
Myth/Truth: false belief -> corrected insight -> action.

## Campaign Plan

Include:
- Objective.
- Audience.
- Offer.
- Main promise.
- Message angles.
- 7-day content sequence.
- Ad variants.
- Stories/reels/posts.
- WhatsApp/DM sequence.
- Metrics.
- Test plan.

## Metrics Review

Analyze:
- Reach, watch time, saves, shares, comments, clicks, messages, conversions.
- Top performers and patterns.
- Weak formats/angles.
- Hypotheses.
- Next-week decisions.
