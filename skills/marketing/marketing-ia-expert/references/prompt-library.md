# Prompt Library

Use this as a compact operational library. For the full source, open the Obsidian prompt library.

## Master Marketing Assistant

```text
Actua como mi estratega de marketing. Mi negocio es [descripcion]. Vendo [producto/servicio]. Mi cliente ideal es [cliente]. Mi objetivo principal es [ventas, seguidores, leads, posicionamiento]. Mi tono debe ser [profesional, cercano, divertido, premium, educativo]. Cuando te pida contenido, responde con ideas accionables, ejemplos concretos y formato listo para publicar.
```

## Brand Diagnosis

```text
Analiza esta marca como consultor de marketing. Marca: [nombre]. Producto/servicio: [descripcion]. Cliente ideal: [descripcion]. Canal principal: [canal]. Dame problema que resuelve, promesa, cliente atraido, tono, contenido recomendado, errores y oportunidades.
```

## Content Bank

```text
Crea 40 ideas de contenido para [marca]. Divide en educativo, autoridad, confianza, entretenimiento, venta, objeciones, historias de cliente y contenido personal. Para cada idea agrega formato, gancho, CTA, objetivo y etapa del embudo.
```

## Hooks

```text
Dame 30 ganchos para [tema]. Clasificalos en dolor, curiosidad, error comun, promesa, historia y pregunta directa. Deben sonar humanos, concretos y no exagerados.
```

## 30-Day Calendar

```text
Crea un calendario de 30 dias para [marca]. Objetivo: [objetivo]. Red principal: [red]. Incluye dia, tema, tipo de contenido, formato, gancho, CTA y objetivo del post.
```

## Ads

```text
Crea 10 anuncios para [producto/servicio]: 3 emocionales, 3 educativos, 2 directos y 2 basados en objeciones. Incluye titular, texto principal, CTA, angulo de venta y publico recomendado.
```

## WhatsApp/DM Sales

```text
Crea una secuencia para vender [producto/servicio] por WhatsApp o DM. Incluye primer mensaje, respuesta a precio, respuesta a 'lo voy a pensar', seguimiento de 24 horas y cierre amable. Tono humano y no insistente.
```

## Results Analysis

```text
Analiza estos resultados: [datos]. Dime publicaciones ganadoras, patrones, temas a repetir, formatos a mejorar, acciones de la proxima semana y pruebas recomendadas.
```
