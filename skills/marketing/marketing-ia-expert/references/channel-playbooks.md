# Channel Playbooks

Use this file when the user asks for channel-specific marketing outputs.

## Instagram / Facebook

Best for:
- hooks
- reels
- carousels
- authority content
- objection handling

Each output should define:
- hook
- format
- visual angle
- CTA
- funnel stage

## TikTok / Shorts / Reels

Best for:
- fast hooks
- myth vs truth
- pain/solution
- short story scripts

Each script should define:
- first 2 seconds
- script beats
- on-screen text
- CTA

## LinkedIn

Best for:
- authority
- B2B positioning
- operational insights
- offer clarity
- case/use narrative

Each output should define:
- opening line
- business insight
- structured body
- CTA

## WhatsApp / DM

Best for:
- lead qualification
- objection handling
- follow-up
- demo invitation

Each sequence should define:
- first contact
- qualification question
- value framing
- objection response
- next step

## Landing Pages

Best for:
- lead capture
- offer explanation
- conversion path

Each landing should define:
- hero
- problem
- promise
- sections
- proof
- objections
- CTA

## Decks / Presentations

Best for:
- sales
- institutional positioning
- product explanation

Each deck should define:
- story order
- audience logic
- proof gaps
- final CTA
