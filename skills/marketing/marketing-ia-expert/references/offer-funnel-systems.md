# Offer and Funnel Systems

Use this file when the user asks for sales messaging, offers, funnels, objection handling, landing logic, or conversion strategy.

## Offer Structure

Define:
- audience
- urgent pain
- desired outcome
- promise
- differentiator
- proof available
- objection handling
- CTA

## Funnel Logic

Map every piece to:
- awareness
- consideration
- conversion
- follow-up
- retention or upsell

## Message Angle Families

Use one or more:
- pain
- desire
- mistake
- opportunity
- comparison
- proof
- objection

## WhatsApp / DM Logic

Minimum flow:
1. entry message
2. qualification
3. value framing
4. objection response
5. next step

## Landing Logic

Recommended order:
1. problem
2. promise
3. how it works
4. benefits
5. proof
6. objections
7. CTA

## B2B Offer Note

For B2B outputs, prefer:
- operational outcomes
- clarity
- continuity
- ROI logic without inventing numbers
- process and support
