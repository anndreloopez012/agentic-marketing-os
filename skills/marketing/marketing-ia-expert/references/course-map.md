# Course Map: Bootcamp Marketing con IA

Use when producing class material, extending the bootcamp, creating exercises, or answering questions about course structure.

## Class 1: Practical Foundations + Brand Analysis

Goal: teach correct AI use and build brand diagnosis, ideal customer, competition, and value proposition.
Deliverables: master prompt, brand diagnosis, 3 buyer personas, 15 content ideas, competitor matrix.
Core concepts: prompt professional, brand diagnosis, buyer persona, pains to content, competitor matrix.

## Class 2: Social Content Creation

Goal: generate useful content for Instagram, TikTok, Facebook, LinkedIn, Shorts.
Deliverables: 40 content ideas, 30 hooks, 5 copies, 5 short-video scripts, 30-day content calendar.
Core concepts: eight content types, hooks, AIDA/PAS, video scripts, editorial calendar.

## Class 3: Campaigns, Ads, Offers, Sales

Goal: build complete campaigns and sales messages.
Deliverables: value proposition, simple funnel, 10 ads, WhatsApp/DM message sequence, 7-day campaign.
Core concepts: irresistible offer, funnel, customer journey, ads, objection handling, sales conversations.

## Class 4: Daily Marketing System

Goal: create a repeatable weekly AI marketing system.
Deliverables: content repurposing system, metrics report, prompt library, final operating workflow.
Core concepts: repurposing, metrics, weekly improvement, prompt library.

## Final Project

Deliver a full 30-day marketing system: diagnosis, client, value proposition, content ideas, calendar, scripts, copies, ads, message sequence, metrics and weekly recommendations.
