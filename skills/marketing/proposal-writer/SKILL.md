# Proposal Writer

Propuestas y cotizaciones profesionales que comunican valor, generan confianza y cierran proyectos.

---

## Estructura de propuesta comercial ganadora

```
1. PORTADA
2. RESUMEN EJECUTIVO
3. ENTENDIMIENTO DEL PROBLEMA / CONTEXTO
4. NUESTRA SOLUCIÓN PROPUESTA
5. ALCANCE DEL TRABAJO (qué incluye y qué no incluye)
6. METODOLOGÍA Y PROCESO
7. ENTREGABLES Y CRONOGRAMA
8. INVERSIÓN (precio)
9. POR QUÉ NOSOTROS (credenciales, experiencia)
10. PRÓXIMOS PASOS
11. TÉRMINOS Y CONDICIONES
```

---

## Sección por sección

### Resumen ejecutivo (la más importante — se lee primero)
- Máximo 1 página
- No hablar de la empresa todavía — hablar del PROBLEMA DEL CLIENTE
- Mostrar que entendiste qué quieren lograr
- Una oración sobre la solución que propones
- Un número o dato que resuma el valor

### Entendimiento del problema
Demuestra que escuchaste y entendiste antes de proponer:
```
"[Nombre empresa] necesita [objetivo principal]. Actualmente, [descripción 
del problema o proceso actual]. Esto genera [consecuencia negativa: pérdida 
de tiempo / costo / errores / oportunidad perdida].

El resultado esperado de este proyecto es [resultado medible]."
```

### Solución propuesta
- Describe la solución en lenguaje del cliente (no técnico)
- Conecta cada componente con un beneficio del negocio
- Usa puntos, no párrafos largos
- Incluye un diagrama o visual si aplica

### Alcance detallado
**Lo que incluye esta propuesta:**
```
Módulo 1: [Nombre] — [descripción breve]
  ✓ Funcionalidad A
  ✓ Funcionalidad B
  ✓ Funcionalidad C

Módulo 2: [Nombre] — [descripción breve]
  ✓ ...
```

**Lo que NO incluye esta propuesta (CRÍTICO):**
```
✗ Integración con [sistema externo] — puede cotizarse por separado
✗ Migración de datos históricos
✗ Capacitación presencial (incluye manual de usuario)
✗ Hosting y servidor (se cotiza por separado)
```

### Presentación del precio

**Nunca presentar solo el número — siempre en contexto de valor:**

```
OPCIÓN A — ESENCIAL
Incluye: [módulos básicos]
Inversión: Q XX,XXX
Tiempo de entrega: X semanas

OPCIÓN B — COMPLETA (RECOMENDADA)
Incluye: Todo lo de Opción A + [módulos adicionales]
Inversión: Q XX,XXX
Tiempo de entrega: X semanas
Ahorro vs cotizarlos por separado: Q X,XXX

OPCIÓN C — PREMIUM
Incluye: Todo lo de Opción B + [soporte, mantenimiento, extras]
Inversión: Q XX,XXX/mes
```

**Técnicas de presentación del precio:**
- Anchoring: presentar siempre la opción más cara primero
- Romper en cuotas si el monto es alto: "Q24,000 en 3 pagos de Q8,000"
- Comparar con el costo del problema: "vs. Q X que cuesta el proceso manual actual"
- Garantía o condición de satisfacción para reducir el riesgo percibido

### Cronograma (hacer que parezca tangible)
```
SEMANA 1-2   Levantamiento y diseño
SEMANA 3-5   Desarrollo Módulo 1
SEMANA 6-8   Desarrollo Módulo 2
SEMANA 9     QA y pruebas
SEMANA 10    Entrega y capacitación

Entrega estimada: [FECHA EXACTA]
```

### Por qué nosotros
- 2-3 proyectos similares con resultados medibles
- Equipo y especialidades relevantes para ESTE proyecto
- Diferenciador específico (no genérico como "calidad" o "experiencia")

### Próximos pasos
Hacer que sea fácil decir sí:
```
Para avanzar con este proyecto:
1. Confirmación de propuesta → [cómo confirmar]
2. Firma de contrato / SOW
3. Pago inicial del [%]% para iniciar el proyecto
4. Kick-off el [FECHA TENTATIVA]

¿Tienes preguntas antes de confirmar? Puedo agendar una llamada 
de 30 minutos para resolverlas: [link de agenda o número]
```

---

## Errores comunes en propuestas

❌ Hablar de la empresa en las primeras páginas (el cliente quiere saber sobre SU problema)
❌ Precio sin contexto de valor
❌ Alcance ambiguo (da pie a malentendidos)
❌ Propuesta genérica que parece copiada de otro proyecto
❌ No incluir qué NO incluye (fuente de conflictos)
❌ Sin próximos pasos claros (la propuesta muere sola)

---

## Cotización rápida (versión simplificada)

Para proyectos pequeños o clientes que piden algo informal:
```
Hola [Nombre],

Aquí la cotización para [nombre del proyecto]:

ALCANCE
[Descripción en 3-5 bullets de lo que incluye]

PRECIO
Q [monto] (IVA incluido / + IVA)
Forma de pago: [50% al inicio / 30-70 / etc]

TIEMPO DE ENTREGA
[X] días/semanas desde la confirmación

INCLUYE
✓ [Item 1]
✓ [Item 2]

NO INCLUYE
✗ [Item 1]

Para confirmar, responde este mensaje o firma la orden de trabajo adjunta.

Saludos,
[Tu nombre]
```
