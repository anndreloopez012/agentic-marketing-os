# Content Strategy Expert

Planificación y ejecución de contenido que construye audiencia, genera confianza y convierte.

---

## Framework de pilares de contenido

Un pilar es un tema central que define de qué hablas. Cada marca necesita 3-5 pilares.

**Cómo definir pilares:**
1. ¿Qué sabe tu marca mejor que nadie? → Expertise
2. ¿Qué le importa a tu audiencia objetivo? → Relevancia
3. ¿Qué conecta tu expertise con sus intereses? → Pilares

**Ejemplo para una agencia de software:**
```
Pilar 1: Tecnología y desarrollo  → tutoriales, tendencias, código
Pilar 2: Negocios y productividad → casos de éxito, procesos, ROI
Pilar 3: Educación y carrera       → tips para devs, aprendizaje
Pilar 4: Cultura y equipo          → behind the scenes, valores
Pilar 5: Industria local           → ecosistema tech de tu país
```

## Calendario de contenido

### Cadencia por canal

| Canal | Frecuencia ideal | Formato |
|---|---|---|
| Instagram Feed | 3-5x/semana | Carruseles, reels, imágenes |
| Instagram Stories | Diario | Encuestas, Q&A, detrás de cámaras |
| LinkedIn | 3-4x/semana | Artículos, carruseles, posts de texto |
| TikTok | 1-2x/día | Videos cortos 15-60s |
| YouTube | 1-2x/semana | Videos largos 8-20min |
| Blog/SEO | 2-4x/mes | Artículos 1500-3000 palabras |
| Newsletter | 1-2x/semana | Mixto: valor + oferta |
| Twitter/X | 3-5x/día | Threads, hot takes, interacción |

### Plantilla de calendario semanal

```
LUNES    — Educación / Tutorial (Pilar 1)
MARTES   — Social proof / Caso de éxito (Pilar 2)
MIÉRCOLES — Entretenimiento / Relatable (Pilar 3)
JUEVES   — Oferta / Producto / CTA (conversión)
VIERNES  — Detrás de cámaras / Cultura (Pilar 4)
FIN DE SEMANA — Repurposed content / engagement
```

## Repurposing: 1 idea → 10 piezas

A partir de un **artículo de blog o video largo:**

```
1. Video largo (YouTube)
   ↓
2. Clip corto de la mejor parte (TikTok/Reels/Shorts)
3. Carrusel con los puntos clave (Instagram/LinkedIn)
4. Thread con insights (Twitter/X)
5. Newsletter con el resumen + link
6. Infografía con el framework principal (Pinterest/IG)
7. Quote visual de la frase más poderosa
8. Podcast narrado (si aplica)
9. Stories con encuestas basadas en el tema
10. Post de LinkedIn con la historia detrás del artículo
```

## Tipos de contenido por etapa del funnel

| Etapa | Objetivo | Formatos |
|---|---|---|
| **TOFU** (awareness) | Descubrir la marca | Reels virales, threads, artículos SEO, videos educativos |
| **MOFU** (consideración) | Conocer la solución | Carruseles, casos de estudio, comparativas, webinars |
| **BOFU** (conversión) | Tomar acción | Testimonios, demos, ofertas, FAQs, garantías |
| **Retención** | Fidelizar | Tips de uso, comunidad, contenido exclusivo |

## Auditoría de contenido existente

Cuando el usuario tiene contenido ya publicado, evalúa:

1. **Inventario:** ¿qué existe? URLs, títulos, fechas, formato
2. **Performance:** vistas, engagement, conversiones, ranking SEO
3. **Clasificación:**
   - ✅ Mantener/optimizar — buen performance
   - 🔄 Actualizar — tema válido pero desactualizado o bajo rendimiento
   - ❌ Eliminar/redirigir — desactualizado, no rankea, no convierte
4. **Gaps:** ¿qué temas no están cubiertos que busca la audiencia?

## Métricas de contenido

| Métrica | Qué mide | Dónde |
|---|---|---|
| Alcance / Impresiones | Cuántos lo vieron | Redes sociales |
| Engagement rate | % que interactuó | Redes sociales |
| Tiempo en página | Calidad de lectura | Google Analytics |
| Scroll depth | Hasta dónde leyeron | GA4 / Hotjar |
| Conversiones desde contenido | ROI del contenido | GA4 + UTMs |
| Ranking SEO | Posición en Google | Search Console |
| Subscribers ganados | Crecimiento de lista | ESP / YouTube |
