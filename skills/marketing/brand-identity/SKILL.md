# Brand Identity Expert

Construcción completa de marca: desde estrategia y posicionamiento hasta sistema visual y voz de marca.

---

## 1. Estrategia de marca (Brand Strategy)

### Brand Foundation (base de toda la identidad)

```
PROPÓSITO      ¿Por qué existe la marca más allá de ganar dinero?
VISIÓN         ¿Dónde quiere llegar en 5-10 años?
MISIÓN         ¿Qué hace hoy para llegar a esa visión?
VALORES        3-5 principios que guían cada decisión
POSICIONAMIENTO ¿Qué lugar ocupa en la mente del cliente vs competencia?
```

### Propuesta de valor única (UVP)
```
Fórmula: "Para [cliente objetivo] que [necesidad/problema],
[nombre de marca] es [categoría] que [beneficio único].
A diferencia de [competidores], [diferenciador clave]."
```

### Arquetipos de marca (Carl Jung)
Define cuál resuena con tu audiencia:

| Arquetipo | Rasgos | Marcas ejemplo |
|---|---|---|
| El Héroe | Ambición, coraje, superación | Nike, FedEx |
| El Sabio | Conocimiento, verdad, guía | Google, BBC |
| El Creador | Innovación, expresión, arte | Adobe, LEGO |
| El Cuidador | Protección, generosidad, servicio | Johnson&Johnson |
| El Rebelde | Disrupción, libertad, cambio | Harley-Davidson |
| El Explorador | Aventura, descubrimiento | National Geographic |
| El Mago | Transformación, visión | Disney, Apple |
| El Gobernante | Control, liderazgo, orden | Mercedes, Rolex |

## 2. Identidad visual

### Sistema de color

**Paleta de marca completa:**
```
Primario     — el color más representativo de la marca (1 color)
Secundario   — complementa al primario (1-2 colores)
Acento       — para CTAs y destacados (1 color vibrante)
Neutros      — blancos, grises, negros para texto y fondos
```

**Psicología del color (referencia):**
| Color | Asociación | Industrias comunes |
|---|---|---|
| Azul | Confianza, profesionalismo, tecnología | Tech, finanzas, salud |
| Verde | Crecimiento, naturaleza, éxito | Ecología, finanzas, bienestar |
| Rojo | Energía, urgencia, pasión | Alimentación, entretenimiento |
| Naranja | Creatividad, accesibilidad, calidez | Educación, B2C |
| Morado | Lujo, creatividad, misterio | Belleza, lujo |
| Negro | Elegancia, exclusividad, poder | Lujo, moda |

**Formato de color en especificaciones:**
- HEX: para digital (#1A1A2E)
- RGB: para pantallas (26, 26, 46)
- CMYK: para impresión (69, 57, 0, 82)
- Pantone: para impresión de alta fidelidad

### Tipografía de marca

**Jerarquía tipográfica:**
```
Display/Hero    — la más expresiva, solo para títulos grandes
Headline        — para títulos de sección
Body            — para texto largo, máxima legibilidad
Mono/Accent     — opcional, para código o detalles técnicos
```

**Pairings recomendados:**
- Serif + Sans-serif = clásico y moderno
- Sans-serif bold + Sans-serif light = minimalista y limpio
- Display expresivo + Neutral body = personalidad + legibilidad

### Logo: dirección y especificaciones

**Variantes mínimas requeridas:**
1. Logo horizontal (versión principal)
2. Logo vertical/stacked (secundaria)
3. Isotipo/ícono (para favicon, app icon, avatar)
4. Versión en blanco (para fondos oscuros)
5. Versión en negro (para fondos claros)

**Zonas de exclusión:** espacio mínimo alrededor del logo = ancho de la letra "X" del logotipo.

**Tamaños mínimos:**
- Digital: 32px de altura mínima para el isotipo
- Impresión: 1cm de altura mínima

## 3. Voz y tono de marca (Brand Voice)

### Definición de voz
La voz es constante. El tono cambia según el contexto.

```
Voz = Personalidad de la marca (siempre la misma)
Tono = Cómo adapta esa personalidad según la situación
```

**Ejercicio para definir la voz:**
"Nuestra marca es como [persona o personaje famoso] porque [razón]."
Ejemplo: "Nuestra marca es como un amigo que es experto en tecnología — te explica las cosas sin hacerte sentir tonto."

### Tabla de tono por canal
| Canal | Tono | Ejemplo |
|---|---|---|
| Website | Profesional + cálido | "Transformamos negocios con tecnología." |
| Instagram | Cercano, inspirador | "Así se ve el lunes cuando tu CRM trabaja por ti 💪" |
| LinkedIn | Experto, datos | "El 73% de las pymes en LATAM no tiene sistema CRM..." |
| Email | Personal, directo | "Hola André, tengo algo que creo te va a interesar." |
| Soporte | Empático, útil | "Entiendo tu frustración. Vamos a resolverlo ahora." |

### Palabras de marca (Word Bank)
Define 10-15 palabras que SÍ usa la marca y 5-10 que NUNCA usa:

```
SÍ usa: soluciones, transformación, resultados, eficiencia, claridad
NUNCA usa: cheap, barato, problemático, complicado, difícil
```

## 4. Brand Guidelines (Manual de marca)

Estructura mínima de un manual:
```
1. Brand Foundation (propósito, visión, misión, valores)
2. Posicionamiento y UVP
3. Audiencia objetivo (buyer persona)
4. Sistema de color (primarios + secundarios + uso)
5. Tipografía (familias + jerarquía + usos)
6. Logo (versiones + zonas de exclusión + usos incorrectos)
7. Fotografía e iconografía (estilo, filtros, qué evitar)
8. Voz y tono (personalidad + ejemplos por canal)
9. Aplicaciones (tarjeta, email, redes, presentaciones)
```

## 5. Auditoría de marca

Cuando el usuario tiene una marca existente, evalúa:
1. ¿La identidad visual comunica lo que la marca dice ser?
2. ¿Es consistente en todos los touchpoints?
3. ¿Se diferencia visualmente de la competencia directa?
4. ¿El tono de comunicación es coherente y reconocible?
5. ¿La propuesta de valor es clara en 5 segundos?

Entrega: tabla de hallazgos con Fortaleza / Debilidad / Acción recomendada.
