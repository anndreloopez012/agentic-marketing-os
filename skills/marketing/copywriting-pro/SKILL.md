# Copywriting Pro

Frameworks y técnicas de copy persuasivo para cualquier formato: ads, landing pages, emails, social.

---

## Frameworks principales

### AIDA
```
A — Attention   → Captura la atención (headline impactante)
I — Interest    → Genera interés (problema o beneficio relevante)
D — Desire      → Crea deseo (solución + beneficios + prueba social)
A — Action      → Llama a la acción (CTA claro y urgente)
```

### PAS (el más poderoso para conversión)
```
P — Problem     → Nombra el problema con exactitud
A — Agitate     → Amplifica el dolor — ¿qué pasa si no lo resuelves?
S — Solution    → Presenta tu solución como la salida natural
```

### BAB
```
B — Before      → La vida del lector ahora (con el problema)
A — After       → La vida del lector después (con tu solución)
B — Bridge      → Lo que conecta: tu producto/servicio
```

### StoryBrand (para marca completa)
```
1. El cliente es el héroe
2. Tiene un problema (externo, interno, filosófico)
3. Encuentra un guía (tu marca)
4. El guía le da un plan
5. El guía lo llama a la acción
6. Que le ayuda a evitar el fracaso
7. Y alcanzar el éxito
```

## Headlines que convierten

### Fórmulas de headline
| Fórmula | Ejemplo |
|---|---|
| Número + Resultado | "7 formas de conseguir clientes sin gastar en ads" |
| Cómo + Beneficio sin dolor | "Cómo duplicar tus ventas sin contratar más vendedores" |
| Pregunta que duele | "¿Por qué tu sitio web tiene visitas pero no ventas?" |
| El secreto de [grupo aspiracional] | "El sistema que usan las mejores agencias de Guatemala" |
| Advertencia | "No lances tu startup hasta leer esto" |
| Promesa específica + tiempo | "Consigue tus primeros 100 clientes en 90 días" |

### Reglas del headline
- Específico > Vago: "Ahorra Q2,000 al mes" > "Ahorra dinero"
- Beneficio > Feature: "Cierra más ventas" > "CRM con pipeline visual"
- Una sola idea — no mezclar mensajes
- Claridad antes que creatividad

## Copy de landing page (estructura completa)

```
HERO
  Headline: [Beneficio principal en 8 palabras máx]
  Subheadline: [Amplía el headline, aclara para quién es]
  CTA primario: [Acción específica]
  Prueba social rápida: X clientes | X estrellas | Usado por [empresa conocida]

PROBLEMA (AGITACIÓN)
  Nombra el dolor con exactitud.
  Usa el lenguaje exacto del cliente (no el tuyo).
  "¿Cansado de...?" / "¿Sabes esa sensación cuando...?"

SOLUCIÓN
  Presenta tu producto/servicio como la salida natural.
  NO empieces con features — empieza con el resultado.

BENEFICIOS (no features)
  ✓ [Resultado 1 que obtiene]
  ✓ [Resultado 2 que obtiene]
  ✓ [Resultado 3 que obtiene]
  Feature → Beneficio: "Pipeline visual" → "Sabes exactamente dónde está cada venta"

CÓMO FUNCIONA
  3-4 pasos simples. Hacer que parezca fácil.
  Paso 1 → Paso 2 → Paso 3 → Resultado

PRUEBA SOCIAL
  Testimonios reales con: nombre, empresa, resultado específico.
  "Gracias a X, logramos Y en Z tiempo" — no "Es muy bueno, lo recomiendo"

OFERTA Y PRECIO
  Presenta el precio dentro de contexto de valor.
  Anchoring: muestra lo que vale antes de mostrar lo que cuesta.
  Garantía para remover riesgo.

CTA FINAL
  Repite el CTA principal con más urgencia o contexto.
  Agrega escasez/urgencia real si existe.
```

## Copy para ads (Meta / Google)

### Estructura de ad de Meta (texto largo)
```
[HOOK — primera línea, decide si siguen leyendo]
Pregunta que duele O dato sorprendente O afirmación polémica

[PROBLEMA — 2-3 oraciones]
Reconoce su realidad actual.

[SOLUCIÓN — tu producto como puente]
Por eso creamos [X]...

[PRUEBA SOCIAL]
"[Resultado específico de cliente real]"

[CTA]
👉 [Acción] → [URL o "Escríbenos"]
```

### Headlines para Google Ads (30 chars c/u)
- Incluye keyword exacta en 1-2 headlines
- Beneficio diferenciador en 1 headline
- CTA en 1 headline: "Solicita Demo Gratis"
- Números si existen: "+200 Empresas Confían"

## Copy para redes sociales

### Hook de post (primeras 2 líneas antes del "ver más")
Los 5 hooks más efectivos:
```
1. Dato contraintuitivo: "El 80% de los negocios fallan por esto (y no es lo que crees)"
2. Promesa directa: "Cómo conseguí 50 leads en 3 días sin gastar en ads"
3. Confesión: "Perdí Q50,000 por no saber esto sobre Facebook Ads"
4. Pregunta retórica: "¿Tu empresa tiene plan de marketing o solo esperanza?"
5. Controversia controlada: "El mejor CRM no es Salesforce (te explico)"
```

### CTA de cierre en posts
- No pidas todo a la vez: elige 1 sola acción
- Específico: "Comenta QUIERO para recibir la guía" > "Comenta abajo"
- Social: "Etiqueta a alguien que necesite ver esto"

## Voice & Tone por audiencia

| Audiencia | Tono | Evitar |
|---|---|---|
| Emprendedores jóvenes | Directo, aspiracional, energético | Corporativo, rígido |
| Empresas B2B | Profesional, orientado a ROI | Demasiado casual o emocional |
| Estudiantes / learners | Accesible, motivador, claro | Jerga técnica, condescendiente |
| C-level / decisores | Conciso, datos, resultados | Promesas vagas, exceso de detalle |

## Checklist de copy antes de publicar

- [ ] ¿El headline dice el beneficio principal?
- [ ] ¿Habla del lector, no de la marca?
- [ ] ¿Es específico? (números, nombres, resultados concretos)
- [ ] ¿Hay una sola idea central?
- [ ] ¿El CTA dice exactamente qué hacer?
- [ ] ¿Eliminé las palabras vacías? (muy, bastante, increíble, realmente)
- [ ] ¿Lo leería alguien en voz alta sin tropezar?
